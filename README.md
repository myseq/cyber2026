# Cybersecurity 2026

The intention of this project is for Cybersecurity Awareness Month (Oct 2026).

And I've decided to have **Passkey** as the main theme for 2026.

## What's Included?

There are 2 things:

 1. An awareness quiz about **Passkey**.
 1. A demo on how **passkey** been used for modern web *authentication*. 

## How It Works?

This project is designed to work on Cloudflare Pages.

Refer to [setup guide](./setup.md) for the setup instruction.
